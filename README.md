# 求职记录

一个简约的本地求职管理工具，帮助你跟踪投递公司、记录面试进展、总结经验。

## 使用方法

**双击 `index.html`** 即可打开使用，不需要启动服务器、安装依赖或打开命令行。

首次打开时，页面会自动载入项目自带的初始记录。以后每次打开都会优先读取当前浏览器中最新保存的数据。

> 请勿使用无痕模式。更换浏览器、移动页面文件或清理浏览器数据后，本地记录可能不可见，请定期导出备份。

### 招聘截图识别（AI 模式）

截图识别需要 Python 3.12 或更高版本，以及阿里云百炼 API Key：

1. 将 `.env.example` 复制为 `.env`。
2. 在 `.env` 中填写 `DASHSCOPE_API_KEY`，不要把该文件分享给他人。
3. 双击 `start-ai.bat`，浏览器会自动打开 `http://127.0.0.1:8765/`。
4. 点击「＋ 新增」，在弹窗顶部选择招聘截图，检查识别结果后再保存。

AI 模式只监听本机地址。截图会在识别时发送到阿里云百炼，但不会由本机服务保存；公司和岗位记录仍只保存在当前浏览器的 localStorage 中。直接双击 `index.html` 时，除截图识别外的功能不受影响。

## 功能说明

### 公司-岗位两级结构
- 一个公司可以投递多个岗位
- 左侧列表点击公司名展开/折叠，显示下属岗位
- 点击岗位查看详情，右侧用标签切换同一公司的不同岗位

### 公司管理
- 点击左下角「+ 添加公司」录入新公司（同时添加第一个岗位）
- 新增公司弹窗支持从单张 PNG、JPEG 或 WebP 招聘截图识别并预填信息
- 公司信息：公司名称、地点、公司备注
- 公司详情页右上角「+ 添加岗位」可追加岗位

### 岗位管理
- 公司信息支持记录地点、企业性质（私企/央国企）和备注
- 每个岗位独立维护：岗位名称、薪资、渠道、投递日期、状态、岗位备注
- 状态：待投递 / 已投递 / 面试中 / 已offer / 已拒绝 / 已挂
- 支持编辑和删除（至少保留一个岗位）

### 投递进展时间线
- 每个岗位下可添加多条进展记录（日期 + 类型 + 结果 + 补充说明）
- 支持投递、筛选、笔试、初试、复试、终面、Offer 等结构化进展
- 按日期自动排序

### 数据统计
- 顶部可切换到独立的「数据统计」看板
- 支持近 7 天、30 天、90 天和全部记录范围
- 展示每日投递、企业性质、岗位状态、投递渠道、求职漏斗和初试通过率
- 图表完全在浏览器本地实时计算，不会上传或额外保存统计数据

### 面试准备
- 每个岗位有独立的面试准备区域

### 经验总结
- 岗位状态设为「已offer」「已拒绝」「已挂」时，自动显示经验总结区域

### 搜索与筛选
- 搜索同时匹配公司名和岗位名
- 按岗位状态筛选

## 数据存储

- 每次增删改后，数据自动保存在浏览器本地存储（localStorage）
- 浏览器中没有记录时，自动从 `data.js` 载入初始数据
- 右上角「导出备份」会下载一个 `data.json` 备份文件
- 「导入备份」可从 JSON 文件恢复数据，并覆盖当前浏览器中的记录
- 仓库中的 `data.js` / `data.json` 为脱敏示例数据，仅用于演示；你的真实记录只保存在本机浏览器中，不会被上传
- 项目中的 `data.json` 是示例备份；浏览器安全机制不允许网页自动覆盖它

## 测试

无需安装依赖，在项目目录执行：

```bash
node --check app.js
node --check data.js
node tests/app.test.js
python -m unittest discover -s tests -p "test_*.py"
```

Node.js 测试覆盖数据流程、旧数据迁移、界面交互与统计口径；Python 测试覆盖本机 AI 服务，未配置 API Key 时也可运行。
